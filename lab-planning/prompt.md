# Task: Create a Marp presentation based on a custom styling theme and a standardized 7-slide Lab Planning guide.

Styling / Theme Parameters:

Format: 16:9 widescreen Marp presentation (size: 16:9, marp: true, paginate: true).

Color Palette: Primary #e0aaff (lavender/purple accent), Secondary #240046 (deep dark violet), Paper #f7edff (soft light background).

Typography & Layout: Custom CSS with a dark title band header (section::before), circular page number badges, styled blockquotes, and a custom CSS grid system (section.grid, section.grid.steps) for card-based list layouts. Special layouts defined for .cover (diagonal split gradient) and .closing (dark solid background with custom radial gradients).

Presentation Structure & Content:

Slide 1 (Cover): Lab Planning: Standardizing Labs — A methodological guide to organizing and presenting Labs. (Prepared by Ayoub Elfaquihi, Supervised by ES-Saraj Fouad, Solicode Tangier / OFPPT).

Slide 2 (Plan/Grid): Presentation Plan outlining the structure (Introduction, Technical Stack, Definitions, Problem & Need, Solution & Implementation, Results & Conclusion).

Slide 3: Technical Stack (Technologies and tools used in the Lab).

Slide 4 (Definitions Grid): Key Definitions (Lab, Technical Lab, Methodological Lab, Quick Start, Hello World, Template).

Slide 5: Problem and Need (Addressing inconsistency in Lab presentations, lack of common structure, and proposing a standard adaptable plan).

Slide 6 (Steps Grid): Solution and Implementation (A standard 7-slide plan and workflow steps).

Slide 7 (Grid): Adapting to the Lab Type (Technical Labs vs. Methodological Labs keeping the same 7-slide structure).

Slide 8: Results and Conclusion (Expected results, standard template deliverable template-lab.md).

Slide 9 (Closing): Conclusion on standardization benefits and next steps (adding the template to the GitHub repository).
