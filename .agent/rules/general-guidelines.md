# General Agent Guidelines

## Core Principles
1. **Clarity & Structure:** Always structure answers with clean Markdown headings, clear bullet points, and concise text.
2. **Modular Architecture:** Maintain separation of concerns across files and modules.
3. **Actionable Steps:** Provide step-by-step guidance that can be directly tested or executed.

## Development Workflow
- Read existing project context before proposing structural changes.
- Ensure all technical documentation remains up-to-date alongside codebase changes.
- Apply consistent formatting standards across all Markdown specifications.
