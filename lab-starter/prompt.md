# Create a brief Marp presentation (Markdown) for a starter lab.

Topic: [This starter lab introduces web developers to the process by
configuring Windows and installing Visual Studio Code along with extensions.]

Structure (7 slides): 1) Title slide with lab title, learner name and
supervisor; 2) Outline; 3) Technical stack with the purpose of each tool;
4) Definitions of key terms; 5) Problem and need; 6) Solution and
implementation with numbered steps, one code example and one test;
7) Results and conclusion.

Rules: keep it brief, with short text and one idea per slide. Use a
beautiful, consistent color palette [navy, blue and mint], a modern layout
and a design that matches the topic [editor-window look]. Use only CSS and
plain Markdown, with no HTML, so it renders the same in VS Code, the Marp
CLI and the web editor. Make sure nothing overflows a slide, and keep code
examples short and simple. Output one .md file.
